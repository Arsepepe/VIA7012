# Goal
Turn an educational problem into a defensible DBR intervention.

# Workflow
1. Define the practical educational problem and context.
2. Identify stakeholders and learner needs.
3. Formulate the design challenge.
4. Derive preliminary design principles.
5. Define the AI-supported intervention.
6. Specify the DBR cycle: analysis, design, implementation, evaluation, redesign.
7. Define evidence to collect.
8. Make explicit how evidence modifies the next iteration.
9. Identify practical and theoretical contributions.
10. Check internal coherence.

# Coherence test
Problem -> Design principle -> Intervention feature -> Evidence -> Finding -> Redesign decision.
